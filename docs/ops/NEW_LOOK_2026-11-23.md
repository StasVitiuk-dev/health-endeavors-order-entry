# New look for the dashboard: three directions (owner request of Nov 22)

Status: PROPOSED · OWNER DECISION REQUIRED (pick one direction) · preview only, off by default.
Nothing is live. With the switch off, the dashboard looks exactly as it does today.

> "Something professional and futuristic, but it should also look very good. Improve everything
> in the visual and colour part, even the smallest details such as buttons and page switching."

## The three directions

| Direction | In one line | Colours |
|---|---|---|
| **Aurora** | Futuristic | Indigo-to-cyan accent, frosted panels, figures in a colour blend, soft glow in dark mode |
| **Graphite** | Professional | Calm graphite greys, one precise teal accent, a thin accent line on top of each figure tile |
| **Original+** | Today's colours, refined | The current blue and greys, with every detail below |

## Details improved in all three

- Sidebar: the open page has a tinted background and a 3 px accent bar; count bubbles are readable.
- Buttons: a soft glow on hover and a small press-down when clicked; a clear focus ring for the keyboard.
- Figure tiles: a border and a small lift on hover. Tables: the row under the pointer is highlighted.
- Status badges carry a small dot. Scrollbars are thin and match the look.
- Page switching: the new page fades and slides in briefly. This only happens when the phone or
  computer allows motion; with "Reduce Motion" turned on there is no animation.
- High-contrast mode (Windows) keeps the system colours.
- Kept from the Nov 3 review: square buttons and fields, one arrow per dropdown.

## How to try it (this browser only)

Feature Flags page → preview switch **New look** → on → choose Aurora, Graphite or Original+ below
the list. The choice applies at once and is remembered in this browser. "Turn all off" goes back
to today's look.

## Checks (local, synthetic data)

- Switch off: no change at all (the Refresh button keeps today's blue).
- The picker applies a direction at once and remembers it; an unknown value falls back to Aurora.
- Readability: every text on 8 main pages, light and dark, in each direction, at or above the
  4.5:1 minimum (3:1 for large text). The first run found 4 problems (grey group labels in
  Graphite and Original+, the sidebar count bubbles, white text on Aurora's blended buttons);
  all fixed on Nov 23.
- Reduce Motion: no page animation. Phone width: no sideways scrolling.
- Result with the preview-switch and module checks: 37 passed, 21 skipped on purpose (tests that
  run at only one size).
- Printing is unaffected: every printout stays black on white in every direction
  (`tests/specs/printers-ext22.spec.js`, see `docs/ops/PRINTING_GUIDE.md`).
