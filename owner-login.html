Returns

Track items customers send back, from request through refund. Status moves through: Requested → Approved or Rejected → Received → Refunded → Closed. Marking a return Received also records what happens to the stock — restocked, moved to Damaged, or discarded — and logs that change to Inventory automatically, so you never enter it twice. Each return is for one specific line item on an order (its full quantity), not a partial amount.

Tax Records

Organizes your income and expense records into a shape your accountant can actually use — categorizes transactions, flags what's missing paperwork, and builds a report you can hand off. It never files anything or talks to the IRS or any state directly — that stays a human decision, always.

Expenses by category

Split into Cost of Goods Sold (ingredients, packaging, manufacturing — the direct cost of what you make) and Operating expenses (everything else). This split is a starting point based on how you've already been categorizing expenses, not tax advice — have your accountant confirm the final categorization before filing anything.

Loading…

Estimated cost of units sold

A separate reference figure — quantity sold × each product's recorded cost — for comparing against the categorized expenses above. This is an estimate, not an authoritative Cost of Goods Sold figure (real COGS accounting also factors in beginning/ending inventory, which this system doesn't track). Items whose SKU doesn't match a product on file, or that have no cost recorded, are called out separately rather than silently left out.

Adverse Event Reports (FDA / MoCRA)

Log any report of a serious reaction to the product here. This calculates the FDA's 15-business-day reporting deadline automatically and opens a high-priority task so it can't be missed. This is a tracking tool, not legal advice — always confirm actual reporting decisions with a qualified regulatory professional.

AI Agent Activity

What each of your 10 agents is allowed to do, what it's actually done, and what it's spent — all in one place.

Agent registry — what each one can touch, and what it can't do alone

Of these 10, only Agent #7 (Customer Service) calls a paid AI model at all — the rest are rule-based checks with no AI model involved, so there's nothing for them to "get wrong" the way an AI reply could.

Each agent has its own On/Off switch below, separate from System Mode — so if one agent is misbehaving you can pause just that one without stopping everything else. Only the Owner or an Administrator can change these; the switch is recorded with who changed it and when. Honest limit: Agents marked "Switch enforced" really check the switch before doing anything. The rest still just record your decision for now; their own code doesn't check it yet, and that's being added one agent at a time. Until an agent says "Switch enforced" below, switching it off is a record of intent, not a guaranteed stop.
