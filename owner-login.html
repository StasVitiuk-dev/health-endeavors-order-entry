Returns

Track items customers send back, from request through refund. Status moves through: Requested → Approved or Rejected → Received → Refunded → Closed. Marking a return Received also records what happens to the stock — restocked, moved to Damaged, or discarded — and logs that change to Inventory automatically, so you never enter it twice. Each return is for one specific line item on an order (its full quantity), not a partial amount.

AI Agent Activity

What each of your 9 agents is allowed to do, what it's actually done, and what it's spent — all in one place.

Agent registry — what each one can touch, and what it can't do alone

Of these 9, only Agent #7 (Customer Service) calls a paid AI model at all — the rest are rule-based checks with no AI model involved, so there's nothing for them to "get wrong" the way an AI reply could.

Each agent has its own On/Off switch below, separate from System Mode — so if one agent is misbehaving you can pause just that one without stopping everything else. Only the Owner or an Administrator can change these; the switch is recorded with who changed it and when. Honest limit: right now this records your decision and shows it here, but the agent's own code doesn't check it yet for most agents — that's being added one agent at a time, starting with whichever ones actually run today. Until an agent says "enforced" below, switching it off is a record of intent, not a guaranteed stop.
